00先看这里

重要事实：GitHub 没有官方中文界面。GitHub 官方在 2016 年就取消了对英文以外界面语言的支持。网上教你"进 Settings → Appearance 选简体中文"的教程是错的——那个地方确实有语言选项，但它只管邮件通知和推荐内容的语言，完全不会改变页面的按钮和菜单。

所以"把 GitHub 改成中文"这件事，只能靠你自己这边的工具。有三种，下面第三种就是这份手册。

01三种翻译方案

① 浏览器整页翻译

最快

右键 → 翻译为中文。按钮菜单立刻变中文。缺点是技术术语可能翻得别扭。

② 汉化插件

最彻底

装 Tampermonkey 扩展 + github-chinese 脚本，全站几乎完整汉化。需要多装两个东西。

③ 这份对照手册

最准

把关键页面的英文逐项对照中文说明。翻译不会出错，操作时对着找即可。

方案一详细步骤（推荐先用这个）

以 Windows 自带的 Edge 浏览器为例：

打开 github.com 并登录

用 Edge 打开 github.com，登录你的账号。

触发翻译

在页面空白处点右键 → 选择「翻译为中文」。

或者看地址栏最右侧，会出现一个翻译小图标，点它 → 选中文。

设置自动翻译

翻译后地址栏会提示，勾选「始终翻译此网站」，以后打开 GitHub 自动变中文。

Chrome 用户：操作一样。右键 → 「翻译成中文」。如果没反应，进 设置 → 语言，添加「中文（简体）」并拖到最上面。

方案二：汉化插件（想彻底汉化再折腾）

装脚本管理器

浏览器扩展商店搜 Tampermonkey（篡改猴），装上。Chrome、Edge 都有。

装汉化脚本

在 greasyfork.org 搜 github-chinese，点安装，Tampermonkey 会弹窗确认。

刷新 GitHub

回到 github.com 刷新页面，导航栏、按钮、菜单就都变中文了。

注意：这类脚本靠解析网页结构来替换文字，GitHub 前端一改版就可能局部失效，通常等作者更新即可。另外要认准知名脚本，别乱装来路不明的。

为什么那三个勾一个都不能动？只要远程仓库里有了任何一个文件（README、.gitignore、License 都算），而你本地也已经提交过内容，Git 就会认为这是两条互不相关的历史，推送时直接报错把你拦下来。空仓库最省事，这是新手翻车率最高的一步。

09官方中文资源

官方中文帮助文档

docs.github.com/zh

GitHub 功能说明的官方中文版，比翻译软件靠谱得多。搞不懂某个功能就去这查。

Git 官方中文手册

git-scm.com/book/zh/v2

Pro Git 完整中文版，免费。想深入理解 Git 原理就读这本。

实用建议：日常操作靠浏览器翻译就够了，遇到关键页面（比如新建仓库、Pages 设置）再翻回这份对照手册核对一遍，避免翻译把重要选项翻错。

顺便说一句：GitHub 全英文这事其实没法完全躲开，命令行报错、技术文档都是英文。但最常用的就那几十个词，用两三周自然就熟了。不用专门背，看得多了就认识。
